# Blueprint Roundtrip Engine (BRE)
**Deterministic engineering preflight, narrow repair-candidate generation and evidence handoff**

![Python](https://img.shields.io/badge/Python-3.11%2B-3776AB?logo=python&logoColor=white) ![unittest](https://img.shields.io/badge/Testing-unittest-4B8BBE?logo=python&logoColor=white) ![Git](https://img.shields.io/badge/Source-Git-181717?logo=git&logoColor=white) ![Local](https://img.shields.io/badge/Execution-Local--first-262A34) ![Status](https://img.shields.io/badge/Status-Internal%20engineering-334155)

BRE is a **private Razorglint engineering system** built to turn an explicitly scoped work unit into deterministic inspection, a reviewable result and a bounded evidence package. It does not silently approve a fix or modify external repositories.

## What exists

| Engineering capability | Verified implementation scope |
| --- | --- |
| Blueprint roundtrip | Restricted Mermaid / JSON intake, deterministic plan and plan digest, human self-attested YAY/NAY, scaffold report and annotated output; **not application generation** |
| Source-aware work unit | Preflight checks of operator-authorized local Git identity and declared operations; review only, no unrestricted shell or trusted sandbox claim |
| Regression + evidence roundtrip | Offline expected/before/after JSON structural comparison and independently verified bounded ZIP evidence |
| Repair recipe 01 | Detached JSON candidate for **exactly one missing object key**, checked against supplied expected data; original source stays unchanged |

## Engineering pattern

```text
SOURCE PIN + SCOPE
        ↓
REPRODUCE / COMPARE
        ↓
BOUNDED CANDIDATE OR REFUSAL
        ↓
VERIFY JSON + EVIDENCE BYTES
        ↓
HUMAN REVIEW / HANDOFF
```

**Qualification basis:** internal synthetic fixtures and documented Python tests in the private `Blueprint-Roundtrip-Engine` repository, inspected at its 3 Nov 2026 main snapshot. This public page is **not** a fresh independent execution or a public cloneable release. No actual customer defect, paid repair, autonomous patch or production target has been claimed.

**Role:** source-pin discipline, regression test design, minimal-change candidate creation, negative-path checks and evidence packaging.
